# Dictation: one start key, the finish key picks the mode

Spec: [[01-screen-capture]]

**Covers:** scap-k1ey, scap-h0ld

Lone tap of Right Ctrl starts dictation; while recording a tap of Right Ctrl finishes as transcription, Shift + Right Ctrl as translation. Remove hold-to-talk, release grace and the Mod5 latches. Shift + Right Ctrl while idle is reserved for screen capture. Target window and prompt rules stay bound to the window focused at start. Update config, examples, GLOSSARY.md and README.
