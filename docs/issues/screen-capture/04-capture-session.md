# Screen capture session on one clock

Spec: [[01-screen-capture]]

**Covers:** scap-st4r, scap-cl1k

Shift + tap of Right Ctrl starts a capture of the focused output: wf-recorder scaled to 1920 px wide, pie's microphone path, click moments from evdev, finish key, all on the monotonic clock. Bundle directory created at start.
