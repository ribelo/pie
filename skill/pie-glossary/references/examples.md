# Worked glossary

A project glossary for a fictional checkout. The description is Polish because that is the dictated language. Terms stay in their typed spelling. Mishearings are Polish phonetic spellings and inflections, plus one error that already showed up in a transcript (`Front Servera`).

```markdown
Narzędzie do dyktowania, które wstrzykuje tekst do aktywnego okna.

- Eio — ejo, e i o
- OpenRouter — open router, open routera
- Nema — NEMa, nema
- Chrome CDP — front servera, chrome cdp, chrome cd p
- gpt-live-transcribe — gpt live transcribe, live transcribe
- dune — djun, dun
- --force — force, dash dash force
```

Leave ordinary words (`build`, `test`, `file`) out even if they appear in the README. Leave an identifier that nobody says (`internal_token_cache`) out even if it is everywhere in the code.

A global line, in `glossary.md` beside `stt.toml`, for a name used in every project:

```markdown
- Pie — pi, paje
```
